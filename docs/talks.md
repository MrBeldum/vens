## Media policy

- **No media files in the repo.** Binaries stay in git history forever, and conference photos can show identifiable attendees.
- **Videos link to the organiser's channel.** Re-hosting loses their view count; only recordings we own go on a venslabs channel.
- **Photos link to the published post** that already carries them with the required photo credit.

Slides live outside this repository (PowerPoint decks). Prefer a PDF export hosted elsewhere, or an HTML deck on the docs site that can be read without downloading.
